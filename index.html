How to wire real models (production)

AiLSA Studio generates previews so you can try every tool instantly. To unlock full-res paid generation, connect your own AI model API keys — then generateVideo() routes through live models:

  • Kling 3.0 Turbo: Kuaishou Kling API or Fal.ai / Replicate proxy
  • Seedance 2.0: ByteDance Seedance API (volcengine)
  • Veo 3.1 / Gemini: Google Vertex AI
  • Claude MCP: Anthropic Claude + AiLSA MCP server (SSE)
  • ChatGPT / GPT-Image: OpenAI API (gpt-4o + gpt-image-1)
  • Voiceover: ElevenLabs / PlayHT • Captions: Whisper API
# .env.example
KLING_API_KEY=sk-...
SEEDANCE_API_KEY=...
GOOGLE_VERTEX_KEY=...
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-proj-...
ELEVENLABS_API_KEY=...

// api/generate.js — live via fal.ai (Vercel)
const res = await fetch('/api/generate', {
  method:'POST', body:JSON.stringify({model,prompt})
})
